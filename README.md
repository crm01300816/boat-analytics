# BOAT ANALYTICS — Codex / Free Web Edition

クラウドでの公開準備と検証手順: [GitHub Pagesへの公開](docs/DEPLOYMENT.md) / [予想精度の検証](docs/EVALUATION.md)。現在の実ファイルはリポジトリ直下にあり、下記の旧説明の `src/*.js` は直下の同名ファイルに読み替えてください。

AppDeployや有料APIを使わない、全国24場のボートレース情報と参考の3連単買い目を閲覧する **ブラウザ用** アプリです。HTML + CSS + JavaScript (ES modules) の静的サイトなので、スマホ側のアプリのインストールは不要です。

> **重要**：統計モデルは未学習・未校正のヒューリスティック（参考値）です。公表済みの的中率や有意な回収率の優位性は確認していません。舟券購入を推奨したり、利益を保証したりするものではありません。舟券購入や投票受付は行いません。

## 動作内容

- 全国24場：開催日・開催場・1〜12Rから選択
- 6艇比較：全国勝率/2・3連対率、当地勝率/2・3連対率、平均ST、モーター/ボート2・3連対率、F本数
- 枠番別：同枠過去10走・枠番別勝率・平均ST
- 当地×枠番別：結果アーカイブを **オンデマンド** 読み込み、選択場・選択枠での過去30/60/90/180日の1着率、2連率、3連率（件数付き）を集計
- 逃げ率/逃がし率：当地の実進入コースが1/2だったレースから算出（艇番・枠番とは区別）
- 展示タイム/スタート展示/進入/気象の表示（公開されたレースのみ）
- 3連単：6艇の相対強度から120通りを評価。3・5・7・10点を選び、**100円単位で合計1,000円** に配分。本命/バランス/穴寄りモード、オッズがある場合は締切前の参考オッズを反映。
- 読み込めなかった値を補間したふりをしない。必須情報が足りない場合は参考予想も出さない。

## データ

[BoatraceCSV](https://boatracecsv.github.io/docs/) の下記CSVをブラウザから取得します。

- `programs/race_cards`, `programs/title`, `programs/waku10`
- `previews/tkz`, `previews/stt`, `previews/sui`, `previews/od3`
- 履歴集計時のみ `results/realtime` と `programs/race_cards` を過去日ごとにJOIN

原データの仕様や更新頻度は上流提供者に依存します。APIではなく公開CSVで、第三者提供元の規約、制限、更新停止、CORSにより利用できなくなる可能性があります。CORS/アクセスエラー時にブラウザから取得できるとは保証できません。上流が変更されたら `src/csv.js` を修正してください。

全国・当地の集計期間は出走表掲載値に依存します。当地×枠番の履歴は指定した直前日数のうち結果CSVが取得できたものに限定するため、**過去3年すべての当地枠番別成績ではありません**。最近の180日で出走数がゼロなら `—` と表示します。

## すぐに使う方法（開発PC）

```bash
cd boat-analytics-codex
python3 -m http.server 8080
# http://localhost:8080 を開く
```

ファイルをダブルクリックして `file://` で開くと、ブラウザのモジュール制限で動かないことがあります。公開して使う場合は次の GitHub Pages を利用してください。

### GitHub Pages 無料公開（Codex対応）

1. GitHub で **公開（Public）** リポジトリを作る（例：`boat-analytics`）。
2. このZIPの中身をリポジトリ直下にアップロードする（ZIPそのものではなく中身）。
3. GitHub の `Settings → Pages → Build and deployment → Source` で **GitHub Actions** を選ぶ。
4. `main` ブランチへのpushで同梱の `.github/workflows/pages.yml` が自動公開します。
5. Actions が成功すると `https://ユーザー名.github.io/boat-analytics/` から利用できます。

追加のNPMパッケージは不要です。GitHub Pagesの無料公開の条件に適合するプランで使用してください。独自ドメインは不要です。

## Codexで編集するには

GitHub リポジトリを Codex で開き、[CODEX.md](./CODEX.md) を指示として読ませてください。デザインを維持しながら修正できるよう `src/analytics.js` と `src/csv.js` に計算・通信処理を分離しています。

## 開発テスト

```bash
node --test tests/*.test.mjs
```

最低限のCSVパース・日付処理・出目120通り・確率の合計・予算1000円・欠損時の予想拒否・当地枠と実コースの区別をテストします。実CSVのブラウザ取得とデータスキーマの更新は別途実機確認が必要です。

## 分析の限界

- 独自スコアは全国/当地勝率、枠別勝率、モーター・ボート成績、ST、直近10走、当地同枠2連率、直前展示の **存在する特徴量のみ** を合成します。未取得項目は重みを除いて平均し直します。気象は表示のみで、学習済みの補正モデルがないためスコアに反映しません。
- 組み合わせ確率はPlackett–Luceのヒューリスティックモデルです。1〜6コース有利差は仮定値です。厳密な過去レースの検証・確率校正は未実施で、モデル確率と実際の的中頻度は一致しない可能性があります。
- オッズは公開の締切前 `od3` の集計中値です。確定オッズとは異なり、欠場/返還への自動追従も保証しません。
- 2026年以前の歴史的アーカイブなど、取得範囲の外を実績として表示しません。成果を断定しないでください。

MITライセンスの BoatraceCSV データを利用。提供元は本アプリと無関係です。ユーザーの個人データをサーバーへ送信・保存する機能はありません。
