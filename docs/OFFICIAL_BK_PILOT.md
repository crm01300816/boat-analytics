## 検証上の留意点

1. Bファイルの当時の公開時刻と保存版の独立証明は行っていません。後日再配布・修正されたファイルの可能性があるため、厳密なリークなし検証と呼びません。
2. Kの払戻データは一般的な3連単決済として処理しています。欠場、返還、特別なレース処理を網羅せず、正式な回収率認定には未達です。
3. B見出し1,116件に対して968件を結合。解析不能の行（6艇揃わないなど）や3連単払戻の欠損によるサンプル偏りを残しています。
4. GitHub Actionsからのダウンロード確認は、Codexクラウドの403制限を解除することとは別問題です。
5. 公式原データ・艇別生データはGitHubへコミットせず、Actionsで集約値のみ保存しています。
