# 実データによる過去検証

アプリの「過去検証」で集計結果を表示します。現行の `analytics.js` とライブ予想は変更していません。候補モデルは比較用であり、ライブへ自動適用しません。

## 取得範囲の調査結果

2026-10-29時点のBoatraceCSV公開Gitツリーを全件調査し、2023-10-29〜2026-10-28の3年間を目標範囲として指定しました。

|データ|公開開始|公開一覧の日数（当日含む）|検証用に収集した行数|
|---|---|---:|---:|
|出走表・選手／モーター成績|2025-05-03|544|82,389|
|着順|2025-11-01|362|54,611|
|確定払戻|2025-11-01|362|54,267|
|枠番別成績|2026-07-19|103|15,924|

提供元の固定コミットは `d9a53dbbec7e5f10f9814782c3dd1dd626aac896`。検証には未完了の当日を含めず、1,367ファイルを取得しました。CSV本体はGit blobのSHA-1と照合し、HTTPS/TLSの検証も維持しています。公開期間内のファイル欠損は2026-06-17です。公開開始前の期間も含む日別欠損一覧、行数、除外理由は `public/backtest.json` にあります。

古い出走表の一部は2026年に後日追加されており、その保存日時を過去に戻して扱うことはできません。Gitコミットの時刻と、そのコミットに実在するファイルを確認し、各レースの予定締切より前の版だけを使いました。Web履歴の取得が429になった時点で停止し、その後は通常のGit転送でコミットメタデータを一括取得しました。

締切前の保存を確認でき、正常な着順と必要成績がそろった範囲は **2026-06-14〜2026-10-28、136日、全国24場、19,810レース** です。3年間の検証を完了したものではありません。2025-11-01以降の全収集結果を調査し、証拠・締切時刻不足などの対象は除外しています。

## 最終テストの実績

学習11,957R（6/14〜9/3）、検証3,870R（9/4〜9/30）、最終テスト3,983R（10/1〜10/28）。全レース1,000円、バランスモード、事前オッズなしの成績です。最終テストの確定払戻欠損は0件です。

|買い目|現行・的中率|現行・回収率|候補・的中率|候補・回収率|
|---:|---:|---:|---:|---:|
|3点|20.34%|75.42%|22.29%|78.27%|
|5点|28.42%|72.41%|31.01%|76.25%|
|7点|34.92%|73.17%|38.29%|75.43%|
|10点|44.01%|74.25%|47.35%|74.27%|

いずれも100%未満で、利益の出るモデルであることは示していません。7点の現行モデルは賭け金3,983,000円に対し払戻2,914,170円。候補は3,004,440円です。

現行モデルのlog lossは4.0844、候補は3.9289。Brier scoreは0.9736→0.9654でした。最終テストの1枠の実際の1着率54.46%に対し、現行の平均予測は31.60%で、1枠を過小評価する傾向がありました。

## 未来情報の扱い

- 特徴量は日別出走表の選手・モーター／ボート成績と、利用可能な締切前版の枠番成績のみ。
- 各日付の収集コミットをGitオブジェクトから特定し、コミットIDを指定したURLからその版を取得します。日時不明の最新ファイルへフォールバックしません。
- 古い日付のファイルを今取得できても、締切前の保存証拠がなければ予想へ使いません。
- 枠番情報欠損5,186レースは欠損のまま扱い、後日の同一選手の成績で補完しません。
- 展示、事前オッズ、実進入、当日の水面情報、節間の着順列、ブラウザで任意収集する当地履歴は予想へ入力しません。
- 締切は結果CSV内の「締切時刻」に記録された予定時刻を、取得版の照合だけに使います。着順、決まり手、実進入、確定人気や払戻は予想生成後に評価用として結合します。
- 枠番別は「実際の1着艇の枠番」による事後集計です。人気別は「的中組番の確定人気」による事後集計です。事前人気の再現ではありません。
- Fフラグ・負のST・6艇の異なる正常着順がそろわないレースを除外します。同着は提供元が順位で列を作るため欠損順位として除外されます。返還・特殊決済を通常の不的中にしません。
- 確定払戻CSVの3連単組番と実着順が一致し、金額が有効な場合だけ精算します。欠損が1件でもある集団全体の回収率はnull。払戻確認分の回収率には別の分母を明記します。

## モデル比較と限界

モデルと分割計画を固定してから結果を集計します。候補は学習期間の1着枠番の観測／予測比を50件ずつの事前値で平滑化して推定します。補正量alpha（0/0.25/0.5/1）と温度（1/0.75/1.25）の12候補から、検証期間のlog lossが最小のものを選びます。今回の選択はalpha=1、温度0.75。最終テストを見て候補やパラメータを選び直しません。

Git時刻はコミッターが記録した日時であり、第三者の時刻証明ではありません。元の予定締切の変更履歴は復元していません。また、現行モデル自体の過去の調整履歴は不明なので、最終テストが過去のすべての開発から独立していたとは断定できません。今回は候補選択で最終テストを使わない設計です。今後の改善にはさらに新しい将来期間での検証が必要です。

標本の少ない場別順位、除外・欠損による偏り、開催日・節による相関を考慮してください。有意差や将来収益を証明するものではありません。過去の展示等を省いたため、ライブの全特徴を使う予想の完全再現でもありません。

## 再実行

追加のnpm依存はありません。Python 3、Git、Node 24を使います。データは `.local/backtest` に保存し、公開サイトへは集計JSONだけを含めます。

```bash
git clone --depth 1 --filter=blob:none --no-checkout https://github.com/BoatraceCSV/boatracecsv.github.io.git /workspace/boatracecsv-archive
git -C /workspace/boatracecsv-archive fetch --unshallow --filter=tree:0 origin main
python3 scripts/collect-history.py --source-repo /workspace/boatracecsv-archive --revision d9a53dbbec7e5f10f9814782c3dd1dd626aac896 --start 2023-10-29 --end 2026-10-28 --out .local/backtest --workers 6
node scripts/run-backtest.mjs --input .local/backtest --out public/backtest.json --work .local/backtest/run-v1
node --test tests/*.test.mjs
node scripts/build-site.mjs
```

既存のデータ用cloneがあれば再利用し、`git clone` は実行しません。固定コミットを含む完全なコミットメタデータが必要です。日別CSVのGit保存は所定の出走表更新コミットを保守的に検出する方式で、見つからない過去版を推測しません。

`experiment.json`、`candidate.json`、モデルのソース、レースごとの入力コミット・予想・精算の監査ログを作業ディレクトリに保存します。同じ作業先で計画や候補が変わった場合は停止します。新規収集時は収集日時によってmanifest hashが変わるため別の作業先を指定します。モデル変更後に既に見た最終テストを再利用して、独立した改善実績とは呼ばないでください。

## 3年間への拡張で残っていること

BoatraceCSVのコードが参照する公式B（番組表）・K（結果）のLZHアーカイブも候補です。ただし今回の環境から以下への接続はプロキシ403となり、3年前の実ファイルの有無・内容・継続性は未確認です。

- `https://www.boatrace.jp/owpc/pc/extra/data/download.html`
- `https://www1.mbrace.or.jp/od2/B/202310/b231029.lzh`

環境設定のネットワーク許可への `www.boatrace.jp` と `www1.mbrace.or.jp` の追加を下書きに保存しました。環境設定でレビュー・保存して環境を公開した後、公式データ取得を再試行できます。許可後も取得可能期間やファイル形式、当時の成績であることを検証してから別の検証計画で組み込む必要があります。未取得の公式データを今回の実績に混ぜていません。
