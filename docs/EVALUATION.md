# 締切前の予想を保存して検証する

既存の `analytics.js` を利用し、表示や予想アルゴリズムは変更していません。精度向上を証明する機能ではなく、検証のための記録・集計機能です。Node 24で追加パッケージなしで実行します。

## 1. 締切前に記録

リポジトリ直下で実行します。クラウドでは既存のHTTPプロキシを利用するため `NODE_USE_ENV_PROXY=1` を付けます。

```bash
NODE_USE_ENV_PROXY=1 node scripts/evaluate.mjs capture --out .local/snapshots/2026-10-29.json
```

日付は実行時の日本時間の当日です。出走表・タイトル・枠別の取得に失敗した場合は停止します。主配信元を直接利用し、代替配信元での成功とは区別します。展示等の任意CSVの取得失敗は記録し、その特徴量を除きます。取得日時が欠損・未来の展示行も使用しません。

全入力を取得した後、締切まで60秒超あるレースだけを保存します。中止・必要情報不足のレースは除外理由を記録します。結果CSVは予想記録時に読みません。120通りの確率、買い目、入力特徴、取得元URL・ハッシュ・時刻、モデルのソースを保存し、既存ファイルの上書きを拒否します。

`.local` はGit管理・Web公開から除外しています。検証中のスナップショットを保持・バックアップしてください。ハッシュは破損検出用であり、第三者による時刻証明や改ざん防止を保証しません。

同じ比較対象にはモデル・mode・countを固定し、同一レースの予想は1件だけにします。日中に再記録する場合は別の比較用ディレクトリを使用してください。都合の良い記録だけを後から選ぶと評価が偏ります。

## 2. 確定結果を保存

開催終了後など、結果がそろってから保存します。日付部分は対象日に合わせて変更してください。

```bash
mkdir -p .local/results
curl --fail --show-error https://boatracecsv.github.io/data/results/realtime/2026/10/29.csv -o .local/results/2026-10-29.csv
```

## 3. 日付で分けて評価

```bash
node scripts/evaluate.mjs report --snapshots .local/snapshots --results .local/results/2026-10-29.csv --split-date 2026-10-29 --out .local/reports/2026-10-29.json
```

`split-date` 未満をbeforeSplit、それ以降をtestに分けます。境界・モデル・パラメータは結果を見る前に固定してください。モデルは固定ヒューリスティックで、この機能は学習を行いません。複数日を評価する場合は同じ列の結果CSVをレースコード重複なしでまとめます。testを見て変更したモデルは、さらに後の未使用期間で評価し直します。

指標は標本数、買い目的中率、120クラスのlog loss（自然対数）とBrier score（全120クラスの二乗誤差の和）、一様確率の比較値、賭け金、払戻、返還、回収率です。log loss/Brierは小さいほど良好です。結果未取得、F、無効な上位着順は除外件数・理由を報告し、通常の不的中へ混ぜません。除外が多い場合は全レースへの一般化に注意してください。

## 払戻額と返還

results/realtimeに確定払戻額がないため、通常は回収率がnullになります。事前オッズを確定払戻として使いません。公式の確定払戻を確認して、例えば次のJSONをローカルに作成します（数値は形式説明用です）。

```json
[
  {"raceId":"202610290101","winningCombo":"1-2-3","payoutPer100Yen":2000,"refundedCombos":[]}
]
```

reportコマンドに `--settlements .local/settlements.json` を追加します。的中の有無にかかわらず対象全レースの確定払戻を入力してください。入力済み対象の賭け金のみを分母にし、回収率 = (払戻 + 返還) / 賭け金です。返還は100円単位の組合せごとに指定します。F・中止・同着等の特殊決済を網羅していないため、それらは別途確認が必要です。CSVで判別できない同着や返還は自動検出できません。実績を公表する前に全対象レースの確定結果・決済との照合が必要です。

## 今回の検証

2026-10-29に実データで締切前92レース分を保存しました。取得済み結果との照合時点では92件とも結果待ちで、実績の標本数は0、精度と回収率は未算出です。テストの人工データによる成功を実レースの精度実績として扱いません。
