# 過去3年検証後に実施する予想方式比較（事前登録）

## 起動条件
GitHub Actions の基準検証 `40822111071` の完了後、成功・一部欠損・失敗を確認し、使えるデータの実在範囲に合わせて比較を開始する。元の基準検証の実行、公開アプリ本体、既存の19,810R監査付きレポートは変更しない。

## 比較対象（結果を見てから有利な条件を選ばない）
1. 現行モデル（バランス、全レース）
2. イン逃げ重視（1枠の事前成績と他艇の強度差）
3. モーター重視（Bの2連対率）
4. 選手成績重視（全国・当地勝率／2連率）
5. 穴狙い（当時の発売前オッズがある場合のみ期待値として評価。ない場合は「事前オッズなしの穴傾向」扱いにする）
6. 見送り条件付き厳選モデル（学習・検証期間だけで選択し、最終テストの成績を見て条件を調整しない）

各方式について、3連単3・5・7・10点、1レースあたり予算1000円、100円単位で比較する。購入見送りのケースは賭け金0円とし、的中率・回収率の分母に混ぜない。選んだレース数・参加率・日数・場数を併記し、極端に少ない標本を成功として扱わない。

## データの扱い
- 公式B（番組表）の全国／当地勝率、モーター等「レース前に入手できたと確認できる」特徴のみ使用。K（着順・払戻）は採点後に結合する。
- 公式の古いBファイルがいつ公開されたか確認できない場合は「探索的な遡及検証」と区別し、リークなしとは断定しない。
- Kの確定人気・確定払戻・着順を、予想の特徴や買い目選択条件へ使わない。
- 展示やオッズの過去データがなければ捏造しない。オッズのないデータで期待値の優位性は主張しない。
- 中止、返還、欠場、同着等の精算を厳密に確認できない対象は回収率の分母と分子から適切に除外し、除外数と理由を公開する。
- データ取得は少量・逐次・緩やかな頻度。403/429の場合は停止して利用条件を確認する。GitHubの公開サイトへ生CSV・元LZH・選手個票は再配布しない。

## 時系列分割（予め固定）
- 学習候補期間：2023-10-29〜2025-10-28
- パラメータ選択期間：2025-10-29〜2026-04-28
- 最終の遡及テスト：2026-04-29〜2026-10-28

※現行モデルは既に2026年の一部を用いて検討された可能性があるため、最終の遡及テストも完全独立とは言えない。最終的な有効性は2026-10-29以後の**新しい未来のレース**で固定ロジックを使って前向きに再検証する。

## 成果物
候補ごとに、検証件数、対象日・競艇場数、購入レース率、3連単の的中数・的中率、総投資、払戻、返還、回収率、条件別成績、既存モデルとの差、データ欠損・除外理由を表示する。

- 回収率100％超えを探す目標は持つが、実際に超えなかった場合は**見つからなかった**と明記する。
- 100％超えがあっても、数十レースだけの偶然のプラスを成果として断定しない。日付別ブートストラップなどで不確実性を示し、見送りにより母集団が変わることを説明する。
- ライブの買い目には自動反映しない。ユーザーに試算の限界とモデル更新案を示してから変更する。
- 過去3年の集計JSON（買い目別の総計）からは新モデルの予想結果を再計算できない。新モデル比較には各レースのB入力とK確定結果を一時的に読み込む再処理が必要。集計済みの月次結果を誤って再利用しない。
